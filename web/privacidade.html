Política de Privacidade do JARVIS

O JARVIS é um assistente pessoal de uso privado, feito e usado por uma única pessoa. Ele não é oferecido ao público.

Dados do Google que o JARVIS acessa

Com a sua autorização, o JARVIS lê a Google Agenda, o Google Classroom (cursos, atividades e avisos) e métricas do YouTube, e busca, lê, baixa e edita arquivos do Google Drive quando você pede. As edições no Drive só acontecem depois de uma confirmação sua.

Como os dados são usados e guardados

  • Os dados são usados só para responder aos seus pedidos.
  • Os tokens de acesso ficam salvos apenas no seu próprio computador.
  • Os dados não são vendidos nem compartilhados com terceiros, e não são usados para publicidade.
  • Trechos necessários para responder a uma pergunta podem ser enviados ao provedor de IA que gera a resposta.

Como revogar o acesso

Você pode remover o acesso a qualquer momento em myaccount.google.com/permissions e apagar os arquivos de token do computador.

O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
